# Project C

Прототип гри та заготівка інтерфейсу з головним меню і налаштуваннями. У задумі це головоломка з механікою інвертації світу, де підлога стає стіною, а стіна — підлогою. Ідея також передбачає використання матричного підходу для реалізації кімнат.

## Структура

- `main.py` — точка входу в гру
- `game_controller.py` — основна логіка керування станами екрану, рендеринг та обробка подій
- `assets.py` — менеджер ресурсів для завантаження зображень, музики та збереження налаштувань
- `menus.py` — реалізація головного меню та меню налаштувань
- `ui_components.py` — допоміжні UI-компоненти (слайдери, анімація)
- `constants.py` — глобальні константи та функція для шрифтів
- `embed/` — папка з мультимедійними ресурсами (зображення, звуки, музика)
- `run_game.bat` — батник для збірки виконуваного файлу

## Встановлення залежностей

Проєкт використовує тільки `pygame`.

```bat
pip install -r requirements.txt
```

## Запуск гри в режимі розробки

```bat
py -3 main.py
```

## Збірка `.exe`

У проєкті вже є `run_game.bat`, який:

1. перевіряє наявність Python і `pygame`
2. встановлює `PyInstaller`, якщо потрібно
3. компілює `.py` файли
4. видаляє старий `dist\Project C.exe`, якщо він існує
5. створює новий виконуваний файл `dist\Project C.exe`

Просто запустіть:

```bat
run_game.bat
```

## Особливості

- прототип головного меню та системи налаштувань
- робота з гучністю музики та звукових ефектів
- збереження налаштувань у `settings.dat`
- завантаження ресурсів із папки `embed`

## Ігрова концепція

У майбутній грі:

- гравець вирішує головоломку, де іноді немає прямого шляху вперед
- застосовується механіка інвертації світу: підлога стає стіною, а стіна — підлогою
- карти/кімнати плануються як матриці, щоб реалізувати простір та логіку руху

## Примітки

- при пакуванні в `.exe` налаштування зберігаються поруч з виконуваним файлом
- вікно гри має заголовок `Project C`
